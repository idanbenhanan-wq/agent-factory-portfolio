# Agent Factory | מערכת לתיאום סוכני AI

**From a client requirement to a controlled delivery workflow, with human approval gates.**

**Idan Ben Hanan | Business Operations · Project Management · AI Implementation**

**Status: in development.** A curated portfolio of an agent orchestration project, with implemented control components and a locally verified stop mechanism. Full multi-agent delivery is not yet verified.

<div dir="rtl">

## מה הפרויקט מנסה לפתור?

בניית פתרון בעזרת כמה סוכני AI דורשת תיאום: מי מנסח את הדרישות, מי בונה, מי בודק, מי מאשר שינויים ומתי עוצרים. ללא הגדרות ברורות, קל לאבד שליטה על היקף, איכות ועלות.

**Agent Factory** מתוכנן לרכז את העבודה מול סוכן מנהל אחד, המנתב משימות לסוכני אפיון, עיצוב, בנייה ו-QA. המשתמש מאשר בארבעה שערים, לפני התקדמות לשלבים הבאים.

## התרומה שלי

אני מגדיר ומוביל את בניית הפרויקט שלב אחר שלב בעזרת Claude Code, מתוך ניסיון בניהול תפעול ופרויקטים. הדגש הוא על תהליך מסירה ברור: אחריות ותוצרים לכל סוכן, קריטריוני קבלה, נקודות אישור, הסלמה, מגבלות עבודה ומדדים.

הקוד והגדרות הסוכנים נבנים בסיוע AI. הפרויקט מוצג כעבודה בפיתוח, ללא טענה לניסיון מסירה אוטונומית בפרודקשן או לכתיבה עצמאית של כל הקוד.

## מה כבר קיים ומה עדיין מתוכנן?

| רכיב | ראיה ומצב |
|---|---|
| חמישה סוכני ליבה | קובצי `pm`, `spec`, `design`, `builder`, `qa` נצפו במאגר המקור; הגדרת pm נכללת כאן כדוגמה |
| חוזה לסוכן המנהל | קיים קובץ המגדיר ניתוב, תוצרים, שערים, הסלמה והגבלת סבבי QA |
| מתג עצירה ו-hook | קוד נכלל כאן; 18 בדיקות קיימות הורצו מחדש וכולן עברו |
| אישור שערים ונעילת מסמכים | קובץ `gate.py` נצפה; יומן ההתקדמות מתאר מימוש ובדיקות חלקיות. לא אומת מחדש במסגרת הכנת המאגר |
| תיאום מלא בין הסוכנים | עדיין לא אומתה ריצה של דרישה עד למסירה |
| מדדי עלות, דשבורד ו-ROI | חלק מהתכנון; אין כאן תוצאות מדידה או הוכחת כדאיות |

ה-README הישן במאגר המקור מציין עדיין ״אין סוכנים״. קובצי הסוכנים ויומן ההתקדמות מראים התקדמות מעבר לכך. מאגר זה מפריד בין מה שנצפה בקבצים, דיווח היסטורי ותוצאה שנבדקה כעת.

## ארבעת שערי ההחלטה המתוכננים

| שער | החלטה אנושית |
|---|---|
| 0 | האם להתקדם, מה ההיקף ומה סיווג הנתונים |
| 1 | אישור דרישות וקריטריוני קבלה |
| 2 | אישור ארכיטקטורה ועיצוב לפני הבנייה |
| 3 | בחינת ראיות QA והחלטה על מיזוג או פריסה בידי אדם |

לפי התכנון, הסוכן המנהל ממליץ ומתאם, והאדם מאשר. הגדרה בקובץ סוכן לבדה אינה הוכחה לאכיפה מלאה.

בסביבת Linux זמנית עם Python 3.12.14 הורצה ב-24.11.2026 הפקודה הבאה. כל **18 הבדיקות עברו**. הבדיקות משתמשות בתיקיות זמניות, כולל שמות בעברית.

## גבולות המאגר הציבורי

זהו מאגר הצגה נפרד, ללא היסטוריית הגרסאות הישנה, נתוני לקוחות או יומני הפעלה פרטיים. הוא כולל רכיבים נבחרים ואינו מערכת תיאום מלאה להתקנה.

ה-hook אינו רשום כאן בתצורת Claude Code. חסרים מנגנון השערים המלא, שאר הסוכנים, תצורת ההרשאות ומנגנון הניתוב. אין לטעון שהעתקת הקבצים האלה לבדה מספקת סביבת אבטחה או בידוד.
